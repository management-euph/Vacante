GeneralRules
User groups 1
Grants user groups:

A customer of this type joins these groups: wholesale prices and terms come with the type, not by hand. On a change of type the customer moves to the groups of the new type.

Account activation 2
New accounts:

Accounts registered on the storefront. The store setting is "Administrator must activate new user accounts".

Invoicing 3
Invoice as:

For invoicing add-ons such as FGO. A company is invoiced with its company name, CIF and Reg. Com., a private person with their name and CNP: show those fields for the type. As the order's data says: a company name or a CIF on the order makes it a company.

Storefronts 4
Works on:

None ticked: every storefront. The type is offered only where it works; with the login rule on, its customers sign in only there.

1Group status after joining comes from the setting "Group status after changing profile type": Active or Pending.
2Per type: an agency waits for approval while private persons are activated as the store usually does.
3FGO reads it on every order of the type: an agency is invoiced as a company (PJ) with its company name, CIF and Reg. Com., a private person (PF) with the name and CNP.
4Multi-storefront stores (Ultimate, Multi-Vendor Plus/Ultimate): the type is used only on the ticked storefronts.
iVendor types have a "Vendor plans" block here instead of activation and invoicing: the plans an applicant of the type can choose.
